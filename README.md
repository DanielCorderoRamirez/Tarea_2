# Tarea 2 — Estructuras iterativas en Python

## 1. Nombre del proyecto

**Tarea 2: Estructuras iterativas en Python — SOFT-01**

## 2. Descripción

Este proyecto corresponde a la segunda tarea del curso Principios de Programación 1 de Universidad CENFOTEC.

Su propósito es aplicar los conocimientos adquiridos sobre estructuras de control, especialmente los ciclos `while` y `for`, mediante la resolución de cuatro problemas prácticos utilizando Python.

La tarea incluye el análisis de los problemas, la elaboración de tablas de variables, diagramas de flujo, implementación de programas y documentación de casos de prueba.

También incorpora seis laboratorios desarrollados durante el curso para reforzar los conceptos de programación.

## 3. Objetivos

**Objetivo general**

Desarrollar soluciones algorítmicas mediante Python, utilizando estructuras iterativas, condicionales, validaciones y variables acumuladoras para resolver problemas prácticos.

**Objetivos específicos**

- Aplicar correctamente los ciclos `while` y `for`.
- Utilizar contadores y acumuladores para procesar información.
- Implementar validaciones de datos ingresados por el usuario.
- Diseñar diagramas de flujo que representen los algoritmos.
- Documentar variables, procesos y resultados.
- Comprobar el funcionamiento de los programas mediante casos de prueba.
- Organizar el código y la documentación en un repositorio de GitHub.

## 4. Funcionalidades

El proyecto contiene cuatro programas principales:

### Ejercicio 1. Control de temperatura de una cámara experimental

Permite simular el incremento progresivo de temperatura de una cámara experimental hasta alcanzar un valor objetivo, utilizando un ciclo `while`.

### Ejercicio 2. Registro de consumo de agua

Permite registrar el consumo de agua durante siete días, calcular el consumo total y promedio, identificar el consumo máximo y contabilizar los días en que se superan los 150 litros.

### Ejercicio 3. Administración de estacionamiento

Implementa un menú interactivo para administrar el ingreso y salida de vehículos, controlar la capacidad disponible, calcular cobros y consultar información del estacionamiento.

### Ejercicio 4. Planificación de recursos de una expedición

Simula el consumo diario de agua y alimentos durante una expedición, actualizando los recursos disponibles y determinando cuántas jornadas pueden completarse.

**Laboratorios complementarios**

Se incluyen seis laboratorios relacionados con estructuras condicionales, selección múltiple, ciclos `while`, ciclos `for`, menús y colecciones.

## 5. Requisitos previos

Para ejecutar los programas se recomienda contar con:

- Python 3 instalado.
- Visual Studio Code.
- Extensión de Python para Visual Studio Code.
- Terminal integrada o consola de comandos.
- Git para el control de versiones.
- Cuenta de GitHub para almacenar el repositorio.

Los programas principales utilizan funcionalidades básicas de Python y se ejecutan mediante consola.

## 6. Instrucciones de ejecución

1. Descargar o clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Localizar el directorio correspondiente a los ejercicios.
4. Abrir el archivo `.py` del ejercicio que se desea ejecutar.
5. Ejecutar el programa desde la terminal utilizando el siguiente comando:

```bash
python nombre_del_archivo.py
```

6. Ingresar los datos solicitados por el programa.
7. Consultar los resultados mostrados en la consola.

Para ejecutar otro ejercicio o laboratorio, se utiliza el mismo procedimiento con su archivo correspondiente.
